<h1 align="center">MERCEN AI Studio</h1>

<p align="center">
  AI-powered image generation, editing and enhancement for Windows.
</p>

MERCEN AI Studio is a desktop application for creating, editing and processing images with artificial intelligence.

The application is designed primarily for local AI processing, allowing supported workloads to run directly on the user's computer.

**Current version:** 1.0.0  
**Platform:** Windows x64

---

## Overview

MERCEN AI Studio provides a unified desktop environment for AI-assisted image creation and processing.

The application combines image generation, editing, enhancement, animation and model management tools in a single interface.

Local processing allows users with compatible hardware to perform AI operations without relying on a remote generation service.

---

## Features

- Text-to-Image generation
- Image-to-Image generation
- AI Inpainting
- Image Upscaling
- Face Restoration
- Background Removal
- Image Animation
- Batch Processing
- Integrated Gallery
- AI Model Management
- Multiple interface languages
- Generation safety controls
- NVIDIA CUDA acceleration

---

## System Requirements

### Operating System

- Windows 10 64-bit
- Windows 11 64-bit

### Hardware

**Minimum**

- 16 GB system RAM
- Compatible NVIDIA GPU
- Sufficient storage for application files and AI models

**Recommended**

- NVIDIA RTX GPU
- 8 GB VRAM or more
- 32 GB system RAM
- SSD storage

An internet connection is required for downloading AI models and related resources.

Performance and memory requirements depend on the selected model, resolution and processing operation.

---

## AI Models

MERCEN AI Studio supports multiple AI models for different generation and image-processing tasks.

AI models are downloaded separately when required and are not included directly in the main application installer.

Model availability and hardware requirements may vary.

## Privacy

Local AI operations are processed directly on the user's computer.

When using local generation, MERCEN AI Studio does not require generated images or generation prompts to be sent to a MERCEN generation server.

Additional privacy information will be provided as online and cloud functionality is introduced.

## Hardware Compatibility

MERCEN AI Studio is currently optimized primarily for NVIDIA GPUs with CUDA support.
